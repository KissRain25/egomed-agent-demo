# EgoMed-Agent 上手指南（新人 30 分钟跑通）

> 面向：第一次拿到这个仓库的人（队友 / 导师 / 交接）
> 目标：**30 分钟内从零到"看到实时分割结果"**，并知道出问题先看哪里
> 配套：`docs/总计划.md`（要做什么）· `docs/API_CONTRACT.md`（接口规矩）· `docs/决策记录.md`（为什么这么定）· `docs/工作日志.md`（踩过哪些坑）

---

## 0. 你要准备什么（5 分钟）

| 项 | 要求 | 怎么查 |
|----|------|--------|
| 操作系统 | Windows 10/11 x64 | — |
| **GPU** | NVIDIA，显存 **≥8 GB**（本项目实测 RTX 5060 Laptop 8GB） | `nvidia-smi` |
| 磁盘 | **≥20 GB** 空闲（权重 ~90 MB + 样例 + 运行产物） | 资源管理器 |
| Anaconda | 已安装（装环境用） | `conda --version` |
| 网络 | 首次装依赖需要（版本已锁定，见 `requirements-lock.txt`） | — |

---

## 1. 装环境（10~30 分钟，一次性）

**双击 `安装环境.bat`** —— 内部三步：建 conda 环境 `egomed`（Python 3.12）→ 装依赖 → 下模型权重。

或手动：

```bat
conda create -n egomed python=3.12 -y
conda activate egomed
python -m pip install -r requirements.txt
python scripts\download_models.py
```

> - **`requirements-lock.txt`** = 本机实测通过的**完整版本清单**（107 个包）。复现环境优先用它；
>   `requirements.txt` 是可读清单（含 SAM2 的 git 地址与固定 commit）。
> - 换机器时若解释器不在常见路径，设环境变量 `EGOMED_PY` 指向它的 `python.exe`（所有 bat 都认）。

---

## 2. 环境自检（30 秒）

**双击 `环境自检.bat`**（等价 `python scripts/check_env.py`）

14 项检查：解释器与 Python 版本 / 必需依赖 / torch+CUDA / 模型权重 / SAM2 源码 / 配置 /
数据样例 / 端口 8000 / 磁盘 / tkinter / site-packages 残留 / git 工作区。

- **全 PASS 才继续**；`WARN` 一般可忽略；`FAIL` 按输出的 `→ 建议` 修完再跑一次。
- 加 `--deep` 会额外导入引擎依赖链（较慢，约 10~20 秒），交付前建议跑一次。

---

## 3. 跑一次（3 分钟）

### 方式 A：图形控制台（**推荐新手**）

**双击 `现场控制台.bat`** → ① 选采集源（默认「视频/帧目录」+ `data/samples/acdc`）
→ ② 点「**机位校准**」（推荐：先确认对得准、看得清）→ ③ 点目标按钮（如「心肌」）→ ④ 点「**开始**」。

> 目标必须先设（契约：**先说话 A2、再发帧 A1**）。点按钮 = 播对应样例语音把目标写进会话。
> 想留素材点「录制」（每秒 1 帧 + 指标 csv，停止时合成 mp4）。

### 方式 B：一键演示（服务端 + 客户端都自动起）

**双击 `启动模拟眼镜.bat`**（会等预热完成再起客户端）。

### 方式 C：命令行（最透明）

```bat
:: 窗口 1：服务端（真引擎，预热 60~130 秒，别关）
python server/api.py --real

:: 窗口 2：客户端
python client/live_client.py --source video --input data/samples/acdc --fps 2 --show
```

**该看什么**：

| 看哪 | 内容 |
|------|------|
| 控制台 / 指标行 | 提交 fps、刷新 fps、P50/P95 延迟、错误数、当前目标、模态 |
| 画面左上 HUD | 会话 id、当前目标、延迟 |
| 画面上 | 服务器返回的分割掩膜（`--display blend` 可与实时画面叠加） |
| 输出目录 | `runs/live/<时间戳>/report.md` + `samples/`（抽样帧，可直接读图） |

## 4. 验收（1~5 分钟）

**双击 `回归.bat`**（等价 `python client/run_regression.py --suite all`）

- **mock 套件 8/8**：协议 / 参数校验 / 坏帧分支（服务端【假实现】，秒级）
- **real 套件 10~11/11**：首帧延迟 / 语音 8 句 / 连续帧出结果（服务端【真引擎】，要等预热）
- 报告：`runs/acceptance/<时间戳>/report.md`；汇总表直接贴群里

> 需要并发用例就 `回归.bat --concurrency 5`（多一个 R3 并发丢帧项）。

---

## 5. 出问题先看哪里（排障顺序）

1. **`环境自检.bat`** → 先排掉 FAIL（版本/依赖/权重/端口四类是绝大多数问题）
2. **服务端日志** `runs/server_log.txt` → 每请求一行：`session / frame / modality / target / wait / infer / 耗时 / status`
3. **一键诊断包** → 控制台「导出诊断包」或 `python client/make_diag_pack.py`
   → `runs/diag/diag_<时间戳>.zip`（环境 + 配置 + 日志尾部 + 各类报告 + 落盘帧 + `summary.md`）
4. 指标异常 → 看 `runs/soak/`（长稳）、`runs/mixed_load/`（并发）里的报告结论行

## 6. 常见问题（都是实测踩过的）

| 现象 | 原因 | 处理 |
|------|------|------|
| 起服务端失败 / 客户端连不上 | **端口 8000 被占用**（上一轮没关） | `netstat -ano \| findstr :8000` → 结束对应 PID |
| 客户端一直提示"请先告诉我要分割哪个器官" | 会话没设目标（契约：先说后看） | 控制台点目标按钮；或 `--audio data/samples/audio/cmd_03.wav` |
| 说"分割左心室"却要求澄清 | "左心室"在 MRI 与超声里都存在（跨模态歧义，契约边界情况 2） | 换更明确的目标（如"分割心肌"），或按返回的 `candidates` 澄清 |
| 首帧很慢（60~130 秒） | 真引擎预热（YOLO + SAM2 + 常用模态 + ASR） | 正常；预热后单帧 ≈500 ms |
| 双击 bat 一闪而过 | 没找到解释器 / 依赖缺失 | 设 `EGOMED_PY`；先跑 `环境自检.bat` |
| pip 反复警告 `Ignoring invalid distribution ~orch` | 上次安装中断留下的残留目录 | 删掉 site-packages 里 `~` 开头的目录（自检会列出来） |
| 中文乱码 | 控制台编码 | bat 已 `chcp 65001`；Python 侧统一用 `mc.log`（带 GBK 兜底） |
| `git push` 失败 | 需要代理 | `git -c http.proxy=http://127.0.0.1:1080 push origin main`；不通就只提交本地 |
| 长跑/评测跑到一半进程消失 | 本机宿主环境的**批量删除守卫**（累计删除达阈值抛 `SystemExit`） | 见 `docs/工作日志.md` 2026-10-08 与派工单 T11：删除处必须 `except (Exception, SystemExit)`；评测前分批清 `pred_mask` |

## 7. 目录地图（哪个文件是干什么的）

| 路径 | 作用 |
|------|------|
| `server/api.py` | **服务端**（A1 发帧 / A2 语音 / `/healthz`），`--real` 开真引擎 |
| `client/live_client.py` | **实时客户端**（采集 → 压缩发帧 → 回显防抖 → 麦克风），源可换（video/cam/url/glasses） |
| `client/live_console.py` | **现场控制台 GUI**（N26）：引导 + 目标 + 实时画面 + 指标 + 录制 + 机位校准 + 诊断包 |
| `client/calibrate.py` + `机位校准.bat` | **引导式机位/佩戴校准**（N36）：抽帧 → 本地质量 + 服务端"有结果"率 → PASS / 需调整 + 原因 |
| 采集/回显适配层（N34/N35） | `GlassesSource` + `GlassesAdapter`（真机只写一个适配器）；`Renderer`（窗口 / 落盘 / AR 镜片） |
| `client/mock_client.py` | **契约库**（压缩规格 / 超时 / 发请求 / `set_target`），两端与工具都复用 |
| `client/acceptance_test.py` | **验收套件**（mock / real） |
| `client/run_regression.py` + `回归.bat` | **一键回归**（N22，自动起停服务端） |
| `client/run_soak.py` | **长稳基线**（N24：fps/P95/内存/显存曲线 + 自动判定） |
| `client/mixed_load.py` | **A1/A2 混合负载压测**（N23：复现并发超时） |
| `client/make_diag_pack.py` | **诊断包**（N28） |
| `scripts/check_env.py` + `环境自检.bat` | **环境自检**（N29） |
| `scripts/egomed_agent/` | 复现评测脚本（离线指标体系） |
| `scripts/demo/` | 复现出来的引擎（YOLO + SAM2 + ASR 封装） |
| `docs/API_CONTRACT.md` | **接口契约**（v1.0 冻结，改接口走 v1.x 流程） |
| `docs/总计划.md` | 总计划与任务状态（N1~N43） |
| `docs/工作日志.md` | 每天做了什么、踩了什么坑 |
| `docs/决策记录.md` | ADR：为什么这么定 |
| `docs/上手指南.md` | **本文件** |
| `data/samples/` | 演示与验收用的样例帧 / 音频 |
| `runs/` | 所有运行产物（报告 / 帧 / 日志 / 诊断包），可随时清 |

## 8. 三条规矩（动手前必读）

1. **接口 v1.0 冻结**：改字段 / 路径 / 错误码 / 响应语义 = 走 v1.x 流程（**提出 → 确认 → 更新契约 → 通知两端**）
2. **单文件单负责人**：`server/**` 归**李**；`client/**`、`docs/**` 归**闫**
3. **验收必须有数字**：改动前后各跑一次 `回归.bat`，把 PASS 数与关键指标贴出来（不接受"感觉好了"）
