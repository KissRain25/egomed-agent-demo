## 2026-09-25（下）：N8 分割精度量化（在线 vs 离线）+ 发现面积过滤误杀小器官

- **新增 `client/eval_segmentation.py`（N8 工具）**：同一批帧跑「在线（HTTP 逐帧，窗口=1）」与「离线（`demo._segment_target` 批处理）」两种模式，对比 Dice/IoU/检出率；`--auto-start` 自动定位「有标注且 YOLO 可检出（conf 与引擎一致 0.3）」的起始帧；报告落盘 `runs/metrics/<时间戳>/`（含逐帧明细）
- **结果（ACDC / myocardium，4 病例 × 8 帧）**：离线 Dice 均值 **0.394** → 在线 **0.403**（各病例差值 −0.030~+0.052，无系统性下降）→ **在线化精度代价 ≈ 0**；同批帧在线延迟 均值 446ms / P95 502ms，而离线必须等整段批处理结束（0.55~0.68s/帧）→ **实时场景不可用**。详见 `docs/指标_分割精度_在线vs离线.md`
- **附带发现（登记 N18）**：引擎 `min_area_ratio=0.001`（帧面积 0.1%）**误杀小器官** —— Amos 病例 100 脾脏标注仅占 **0.028%** → 检出 **0/8**；`--min-area-ratio 0` 关闭过滤后 **8/8 检出、Dice 0.705±0.027**。ACDC 心肌占 0.18% 故未受影响（解释了为何只在 Amos 暴露）
- **方法学教训（已写入指标文档 §四）**：① 数据集许多帧本无标注，只看前几帧评估会得 Dice=0；② “有标注 ≠ 可检出”，筛选阈值须与引擎一致；③ 在线掩膜是压缩后 960×1280，需上采样对齐标注再比；④ 部分 PNG 读出 (h,w,1) 需压成二维
