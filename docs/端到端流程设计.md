## 二、端到端架构（三层职责）

```
┌─────────────────────────────────────────────────────────────┐
│ 眼镜端（Glasses / 模拟层）——"数据接收 + 对话交互"               │
│                                                             │
│  [摄像头] 第一人称画面帧 ──→ 压缩(≤1280px/80/300KB) ──┐       │
│  [麦克风] 医生语音短录音 ──→ wav/amr 编码 ────────────┤       │
│  [本地逻辑] 会话管理(session_id) / 发帧节奏控制 /      │       │
│             上一帧保留(防抖) / 网络重试               │       │
│                                                    ↓       │
│  [显示] overlay 结果回显 + 提示语("请对准屏幕")       │       │
└──────────────────────┬──────────────────────────────────────┘
                       │ HTTP 一问一答（契约 v1.0 冻结）
                       │  A1: POST /api/v1/frame（画面→分割结果）
                       │  A2: POST /api/v1/audio（语音→文本+目标）
                       ↓
┌─────────────────────────────────────────────────────────────┐
│ 服务器端（RTX 5060）——"处理数据"                              │
│                                                             │
│  A1 链路: 模态分类(MRI/CT/超声/X光/内窥镜) → YOLO 检测        │
│           → SAM2 分割/跨帧跟踪 → overlay(base64) 回传        │
│  A2 链路: ASR(asr_medical, 谐音优化) → NLU(文字→分割目标)     │
│           → 目标写入会话状态 → 后续 A1 按该目标分割           │
│  [会话态] session 内: 当前目标 / 模态防抖 / 坏帧返空          │
│  [性能] 启动预热(首帧 5~42ms) / 并发 latest-wins(238ms)       │
└─────────────────────────────────────────────────────────────┘
```

**一次完整使用流程（医生视角）**：

1. 医生戴上眼镜看向屏幕上的医学影像 → 眼镜端持续/按需发帧（A1）
2. 服务器识别模态 + 分割默认目标 → overlay 回显在医生视野
3. 医生说"帮我分割左心室"（A2）→ ASR + NLU 解析出目标 → 写入会话
4. 下一帧起分割结果切换为医生指定目标
5. 医生转头/遮挡（坏帧）→ 服务器返空 overlay → 眼镜端**保留上一帧画面** + 提示"请对准屏幕"（不闪跳、不黑屏）
6. 医生换病人/换屏幕 → 新 session，会话状态重置

## 三、职责边界（导师定的分工 × 契约映射）

| 职责 | 归属 | 已有实现 | 备注 |
|------|------|---------|------|
| 画面/语音采集与压缩 | 眼镜端 | `mock_client.py`（选文件模拟）| N4 升级为摄像头流 |
| 对话交互（回显+提示） | 眼镜端 | 结果图落盘 `runs/stream/` | N5 升级为实时回显窗口 |
| 会话管理发起 | 眼镜端 | `make_session_id()` | — |
| 数据处理全部（识别/检测/分割/ASR/NLU） | 服务器 | `server/api.py`（真引擎） | 李负责，v1.0 冻结 |
| 状态语义（目标切换/防抖/丢帧） | 服务器 | 契约第五节 + A.10 已验收 | — |

**核心设计决策**：眼镜端**零智能、零模型**——只做采集、压缩、发送、显示、保留上帧。所有计算在服务器。好处：眼镜端极轻（未来任何 AR/智能眼镜都能跑），且模型升级不动眼镜。
