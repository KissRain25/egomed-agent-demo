## 三、本轮修掉的两个真 bug

| bug | 现象 | 根因 | 修法 | 验证 |
|---|---|---|---|---|
| 掩膜尺寸不匹配 | 长稳 11/3504 请求 HTTP 500（`boolean index did not match...`） | `_segment_target` 用**首帧**尺寸建标签图，而 `overlay_prediction` 的 `vis` 是**当前帧**尺寸；窗口残留 2 帧且两帧尺寸不同即触发 | 标签图按当前帧尺寸建，掩膜统一降维并 resize（`scripts/demo/egomed_demo.py`） | 只读复现脚本 `scripts/diag_mask_shape.py`：修前 `--keep 2` 必崩，修后 **30/30 通过** |
| 契约版本常量漏同步 | 诊断包/关于页/便携包 README 报 `v1.0.3` | 变更记录早已写 v1.0.4，常量没跟 | `launcher.py` + `client/live_console.py` + `API_CONTRACT.md` 头部统一 | `launcher.py --version` → `contract v1.0.4` |
